## Byte index and verification

`index.json` is a reviewed object with `schema:"ruyitrace-site-operations-index.v1"`, full `source_commit`, release `source_tag`, boolean `emergency`, and `raw_sha256` mapping **every fixed `raw/`-relative path** to the SHA-256 of its unmodified bytes. Generate only after collection and review; keep keys sorted and a trailing newline. The platform gitlink for `submodules/ruyitrace` must match `source_commit` in a Git checkout. Pass `--source /absolute/local/source/clone` when available: its `HEAD` and `arm64-site-ops-v1` must resolve to the indexed source commit. The verifier also checks reviewed source ancestry and installed source-file hashes, with no fetch or remote call.

From the platform clone: `python3 -B scripts/verify-trace-site.py`. The verifier checks published bytes and receipt concordance offline; an unsigned receipt set remains a reviewed operational observation, not cryptographic attestation of real-world execution. Keep the status pending until the evidence and integration both pass.
